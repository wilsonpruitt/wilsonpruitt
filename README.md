# Wilson Pruitt

Pastor of Covenant United Methodist Church in Austin, Texas. I run **Wroot Press**, a small imprint for translations and reading tools, and **Wroot Labs**, which builds tools for churches.

Most of what's here is public-domain texts made readable in English, plus tools I built for the United Methodist world.
